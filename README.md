Motivation Timer
This is a simple pomedero-style customizable time I made for my girlfriend.

built with Streamlit and Poetry.

Features

    Adjustable Timer: Set custom durations for work sessions, short breaks, and long breaks in both minutes and seconds.

    Optional Long Break: The user can enable or disable the long break feature. If enabled, the app will automatically trigger a longer break after a user-defined number of work cycles.

    Start/Pause Functionality: A single button dynamically changes its function to either start or pause the timer, providing a clean and intuitive user interface.

    User Profiles: Save and load custom timer settings as profiles. This allows users to easily switch between different configurations for various tasks (e.g., "Deep Focus" or "Quick Task").

    Progress Bar: A visual progress bar provides a clear representation of the time remaining in the current session.
